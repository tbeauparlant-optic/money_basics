# Rebuild Layer

This folder is a non-destructive rebuild sandbox nested under the current repository.

## Purpose

- Preserve all current assets while moving to a scalable structure.
- Keep legacy and refactored content side by side.
- Enable phased migration without breaking existing paths.

## Key Areas

- `content/`: canonical learning content and legacy imports
- `assets/`: raw and processed media
- `src/`: web/site/activity source code
- `config/`: schemas and site/workshop configuration
- `docs/`: architecture and migration documentation

See `docs/migration-map.md` for exact path mappings.
