Resources

Contents included here
- `h5p-workbench/README.md`: overview of the active H5P workbench
- `h5p-workbench/docs/`: workflow and validation notes
- `h5p-workbench/content-types/`: custom H5P libraries with scripts, styles, semantics, and library metadata
- `h5p-workbench/content-instances/`: sample H5P instances and package metadata
- `h5p-workbench/packages/workbench-placeholder-test.h5p`: minimal sample package
- `README.md` and `info.txt` copied from legacy/reference notes

Tooling note
- This repo does not currently have a dedicated active `tools/` set specifically for H5P packaging.
- The practical build guidance lives in the H5P workbench docs, especially:
  - `docs/minimal-scaffold.md`
  - `docs/package-validation.md`
  - `docs/setup-notes.md`

Use this folder as the supporting bundle for maintaining or extending the custom H5P activities copied into the workshop folders.
