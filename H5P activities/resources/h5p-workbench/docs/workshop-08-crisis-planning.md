# Workshop 8 Crisis Planning

Date: 2026-04-07

## What Was Built

- `content-types/H5P.CrisisPlanning-0.1/`
  - A minimal custom H5P worksheet for Workshop 8 crisis planning.
- `content-instances/crisis-planning-demo/`
  - A matching sample instance for packaging and Lumi import.

## Layout Choice

This activity keeps the worksheet as one four-step flow:

- self-check on how finances affect well-being
- self-check on how mental health or health issues affect finances
- crisis replacement planning
- expense tracking and trusted support planning

The worksheet is intentionally kept simple:

- no scoring
- no completion logic
- no navigation chrome
- learner-entered fields only
